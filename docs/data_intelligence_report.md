PSI is univariate and cannot see a joint shift; the adversarial classifier can, and its permutation importances name the columns responsible. The two runs matter. The first separates perfectly because the test panel is simply a later period -- a restatement of how the split was made, not a finding. The second removes the calendar and asks whether the cross-section itself has moved.
